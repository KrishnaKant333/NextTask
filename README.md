# NextTask

A full-stack To-Do List Web Application built using the MERN stack. NextTask is designed to help users efficiently manage their daily tasks through a clean and intuitive interface.

## Project Status

Currently under development. I am actively working on NextTask and continuing to improve its features, functionality, and overall user experience.

## Tech Stack

- MongoDB — Database
- Express.js — Backend framework
- React.js — Frontend library
- Node.js — Runtime environment

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Manage tasks dynamically
- Edit and save existing tasks
- Persistent task storage using MongoDB
- RESTful API for communication between frontend and backend
- Responsive and interactive user interface

## Future Improvements

As development continues, I plan to introduce additional functionality such as:
- Task filtering and sorting
- Task priorities
- Due dates and reminders
- User authentication
- Improved UI/UX
- Additional productivity features
